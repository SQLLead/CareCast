{% docs forecast_training_history__overview %}
Append-only incremental table that records one row each time a Snowflake ML forecast
model is trained (or retrained). Each run appends a new row; historical training
events are never updated or deleted (`full_refresh=false`).

The model body is generated by the `log_forecast_training` macro, which queries the
training input view to capture row counts and date range at the moment of training.
A `create_forecast_model` pre-hook runs first to issue the
`CREATE OR REPLACE SNOWFLAKE.ML.FORECAST` statement before the log row is inserted.

The target model is specified at run time via the `forecast_model` dbt var.

**Training a model:**
```
dbt run -s forecast_training_history --vars '{run_forecast: true, forecast_model: <model_name>}'
```
{% enddocs %}

{% docs forecast_training_history__model_name %}
Identifier for the Snowflake ML forecast model, matching `model_name` in
`forecast_registry`.
{% enddocs %}

{% docs forecast_training_history__forecast_model_fqn %}
Fully-qualified name of the Snowflake ML object created during training, in the form
`<database>.<schema>.<model_name>`. Used to call the model at forecast execution time.
{% enddocs %}

{% docs forecast_training_history__training_timestamp %}
Timestamp when the training run executed (`current_timestamp()` at insert time).
Represents when the Snowflake ML model was created or replaced.
{% enddocs %}

{% docs forecast_training_history__model_status %}
Status of the model at training time. Always `ACTIVE` for rows inserted by the
`log_forecast_training` macro.
{% enddocs %}

{% docs forecast_training_history__model_type %}
The ML framework used to train the model. Always `SNOWFLAKE_ML_FORECAST` for models
managed by this pipeline.
{% enddocs %}

{% docs forecast_training_history__input_ref %}
The dbt model name used as training input, sourced from `forecast_registry.input_ref`
at the time of training (e.g., `vw_fact_care_gap_ff_fcast`). Records which view the
model was trained on.
{% enddocs %}

{% docs forecast_training_history__series_colname %}
The column used to partition training data into separate series, sourced from
`forecast_registry.series_colname` at training time (e.g., `health_plan`).
{% enddocs %}

{% docs forecast_training_history__timestamp_colname %}
The date/time column used as the time axis during training, sourced from
`forecast_registry.timestamp_colname` at training time (e.g., `vb_report_month`).
{% enddocs %}

{% docs forecast_training_history__target_colname %}
The numeric column the model was trained to predict, sourced from
`forecast_registry.target_colname` at training time (e.g., `member_count`).
{% enddocs %}

{% docs forecast_training_history__training_rows %}
Total number of rows in the training input view at the time of training. Useful for
detecting training data size changes between retraining events.
{% enddocs %}

{% docs forecast_training_history__training_start_date %}
Earliest timestamp value in the training input view, cast to date. Represents the
beginning of the historical window the model was trained on.
{% enddocs %}

{% docs forecast_training_history__training_end_date %}
Latest timestamp value in the training input view, cast to date. Represents the
training data cutoff — the last actual period the model has seen. Equivalent to
`data_as_of_month` in `forecast_run` for runs executed immediately after training.
{% enddocs %}

{% docs forecast_training_history__created_by %}
The Snowflake user (`current_user()`) who executed the training run.
{% enddocs %}

{% docs forecast_training_history__model_database %}
The Snowflake database where the ML model object was created. Reflects the target
environment (`_dev` suffix in dev, production name in prod).
{% enddocs %}

{% docs forecast_training_history__model_schema %}
The Snowflake schema where the ML model object was created. Reflects the target
environment (user-prefixed schema in dev, standard schema in prod).
{% enddocs %}
